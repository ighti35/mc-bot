# Claude Bot Inventory (Minecraft 1.21.11 / Fabric)

## 游戏内建筑菜单

输入客户端命令 `/botbuild`，或在 `/botinv` 背包管理界面点击右上角“建筑图纸”。新增菜单需要重启 Minecraft 后加载更新后的模组。

所有已安装图纸自动列入目录，中文名称、真实图纸俯视预览、占地、建筑高度和方块数量均从图纸读取。图纸数量取决于本机已安装的图纸包。支持分类、翻页、放大预览、设置中心 X/Z 与底层 Y、使用主人或机器人当前坐标、建造、按保存原址续建和停止。基础房型尺寸修改后自动更新预览。

默认保留已有地形。“清理地形：开启”明确授权本次新建筑范围内的清理；续建使用已保存的原址和原先授权，当前坐标不改变断点。创造模式默认允许指令；其他模式需点击“本次指令：授权”，授权只覆盖这次任务。

客户端通过本机 127.0.0.1:52592 与机器人通信，所以菜单适用于当前同机的单人局域网环境。只有机器人配置中的主人可取得会话令牌并发起操作；不接受网页 Origin 或跨站请求。HTTP 调用和图纸加载异步进行，不会阻塞游戏渲染线程。关菜单后建造继续，停止按钮才会取消任务。

`/botinv` 默认管理 Claude_Bot；`/botinv <player>` 或 `/invsee <player>` 指定玩家。需要 GAMEMASTERS 权限。宿主和客户端均须加载本模组，单人局域网的宿主安装一次即可。Mineflayer 机器人无需加载 Fabric。

本模组直接引用目标玩家的真实 PlayerInventory，不用复制背包后覆盖的方式。盔甲槽校验装备类型，数量限制为 1，尊重绑定诅咒；副手接受普通物品。数据槽只读且隐藏。双方背包、快捷栏可拖放和 Shift 点击。关闭窗口时，游戏原生容器机制将光标物品交回打开窗口的玩家。目标死亡、离线、跨维度或管理权限失效时窗口失效。同一个目标只允许一个管理窗口。

生命、最大生命、吸收生命、饥饿、饱和度、护甲和全部状态效果每 5 tick 同步；状态效果附带等级、持续时间、初始/延长后的时长和正负效果标记。超过 8 种效果时，最后一栏悬停查看其余效果。

服务器私发 `[BOT_UI] OPEN/CLOSE <owner>` 信号；Node 模块 modules/game-inventory.js 只接受完全匹配且主人名称一致的消息，暂停任务和自动进食，避免操作背包时抢占装备。关闭窗口不自动恢复旧任务。每秒发送 OPEN 心跳以补上初始化期间的遗漏。

`build.ps1` 使用现有 Java 21 和 Minecraft 1.21.11 的精确依赖进行 javac 编译，再使用 Fabric Tiny Remapper 将 Yarn 命名转换为运行时 intermediary 命名。编译依赖、Yarn 1.21.11+build.6、Tiny Remapper 0.11.2 和独立测试环境保存在工作区 work/bot-inventory-build。安装的 JAR 不包含游戏、测试库或测试用访问修改。

验证：真实 Minecraft 容器代码的 17 项本地检查（使用服务器玩家测试替身），覆盖实际拖放、Shift 转移、装备限制、原生装备变更回调、物品组件、数量守恒、实时状态、只读数据槽与死亡关闭条件。机器人端另有界面暂停、拒绝伪造聊天信号及断线清理检查。游戏画面需重新启动 Fabric 后加载。
